## ETL Traffic Collision Analysis

This project uses PySpark to prepare and analyse traffic collision data. It includes the working notebook and the project report.

### Project files

- [ETL notebook](ETL_Traffic_Data_Analysis_Nachiket_Patel.ipynb)
- [Project report (PDF)](ETL_Traffic_Data_Analysis_Nachiket_Patel.pdf)

The notebook was prepared for Google Colab and expects the source data in the connected Google Drive folder. The dataset is not included in this repository. AWS credentials are expected to be configured through Colab Secrets if running the optional S3 upload section.
